# Proyecto Web Dinámica 📱

Este es un proyecto académico: una app móvil hecha con **React**, con funcionalidades típicas.

## 🛠 Funcionalidades principales

- Registro e inicio de sesión de usuarios con **autenticación**.  
- Base de datos con **Firebase**.  
- Checklists personalizados para cada usuario.  
- Operaciones **CRUD** en Firebase: Alta, Baja y Modificación de objetos.  
- Notificaciones dentro de la app (mensajes / alertas internas).  
- Ventanas emergentes (modales) para interacción con el usuario.

## 🚀 Tecnologías usadas

React, JavaScript, Firebase (Authentication & Firestore / RTDB), componentes UI, etc.
